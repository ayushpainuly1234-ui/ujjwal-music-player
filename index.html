A LITTLE ABOUT THIS PROJECT

Built with music & code.

Hi, I'm Ujjwal. I built Ujjwal Music as a small web development project while learning HTML, CSS and JavaScript.

I wanted to make a music player that was simple to understand but still had useful features. You can search for songs, play or pause music, use next and previous controls and move through a song using the progress bar.

This is a learning project, so I plan to keep improving it as I learn more about web development and JavaScript.
